# Expense Tracker (Java CLI)

Project URL: https://roadmap.sh/projects/expense-tracker

A simple console-based expense tracker written in Java. Add, update, delete,
and view your daily expenses, and get a monthly total — all from the terminal.

## Features

-  Add an expense (description + amount, date auto-filled with today)
-  Update an existing expense by id
- Delete an expense by id
-  View all recorded expenses
-  Monthly summary — total spent in a chosen month
  

## Tech Stack

- **Java 17+** (uses text blocks and `switch` expressions)
- `java.time.LocalDate` for dates
- `java.util.ArrayList` for in-memory storage
- `java.util.Scanner` for input

No external dependencies.
